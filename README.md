## This project is part of my learning journey into understanding how JSON is lexed and parsed.

I chose a recursive descent parsing approach. While this approach relies on the call stack and can introduce stack-depth limitations, it offers a straightforward implementation and can be particularly suitable for resource-constrained embedded systems.
I'm still exploring ways to improve the implementation, so feedback is very welcome.
